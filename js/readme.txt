==============================================================
  Claude Code 간단 사용 설명서 (VS Code 기준)
==============================================================

Claude Code는 Anthropic이 만든 AI 코딩 도우미입니다.
코드를 읽고, 수정하고, 터미널 명령을 실행하고, 설명해 주는 등
프로젝트 작업을 대화로 함께 진행할 수 있습니다.


--------------------------------------------------------------
1. 준비물
--------------------------------------------------------------
- VS Code (최신 버전 권장)
- Claude 계정 (Pro / Max / Team / Enterprise 요금제)
  또는 Anthropic Console(API) 계정
- 인터넷 연결


--------------------------------------------------------------
2. 설치 방법
--------------------------------------------------------------
1) VS Code 왼쪽의 [확장(Extensions)] 아이콘 클릭 (Ctrl+Shift+X)
2) 검색창에 "Claude Code" 입력
3) Anthropic이 배포한 "Claude Code" 확장 설치
4) 설치 후 VS Code 오른쪽 위 또는 사이드바에 생긴
   Claude 아이콘(별 모양)을 클릭
5) 처음 실행 시 안내에 따라 Claude 계정으로 로그인


--------------------------------------------------------------
3. 기본 사용법
--------------------------------------------------------------
- 작업할 프로젝트 폴더를 VS Code로 엽니다. (파일 > 폴더 열기)
- Claude 패널을 열고 입력창에 원하는 작업을 한국어로 적습니다.

  예) "이 프로젝트 구조를 설명해줘"
      "index.html에 다크 모드 버튼을 추가해줘"
      "이 에러가 왜 나는지 찾아서 고쳐줘"

- Claude가 파일을 수정하려 하면 변경 내용(diff)을 보여주고
  승인을 요청합니다. 확인 후 수락 또는 거절하면 됩니다.
- 터미널 명령 실행 전에도 허락을 구합니다.


--------------------------------------------------------------
4. 유용한 기능
--------------------------------------------------------------
[파일/코드 지정하기]
- 입력창에 @ 를 입력하면 파일을 골라 대화에 첨부할 수 있습니다.
  예) "@style.css 의 색상을 파란 계열로 바꿔줘"
- 에디터에서 코드를 드래그(선택)한 상태로 질문하면
  선택한 부분을 Claude가 자동으로 참고합니다.

[모드 전환]
- 입력창 아래의 모드 버튼으로 동작 방식을 바꿀 수 있습니다.
  · 기본 모드   : 수정할 때마다 승인 요청
  · 자동 수락   : 파일 수정을 자동으로 승인
  · 계획(Plan)  : 코드를 바꾸지 않고 먼저 작업 계획만 세움
    → 큰 작업은 계획 모드로 먼저 확인하는 것을 추천

[되돌리기]
- 이전 메시지 지점으로 대화와 코드 변경을 되돌릴 수 있습니다.
  (체크포인트/되감기 기능)
- 그래도 Git으로 중간중간 커밋해 두는 것이 가장 안전합니다.

[대화 기록]
- 이전 대화를 다시 불러와 이어서 작업할 수 있습니다.
- 새 주제는 새 대화로 시작하는 것이 정확도에 좋습니다.


--------------------------------------------------------------
5. 자주 쓰는 슬래시(/) 명령어
--------------------------------------------------------------
입력창에 / 를 입력하면 명령어 목록이 나타납니다.

  /init        프로젝트를 분석해 CLAUDE.md 파일 생성
  /clear       현재 대화 내용 초기화
  /compact     긴 대화를 요약해 공간 확보
  /model       사용할 Claude 모델 변경
  /memory      CLAUDE.md(기억 파일) 편집
  /permissions 허용/차단할 도구 권한 설정
  /mcp         외부 도구(MCP 서버) 연결 관리
  /resume      이전 대화 이어가기
  /code-review 현재 변경사항 코드 리뷰
  /help        도움말 보기


--------------------------------------------------------------
6. CLAUDE.md 활용하기
--------------------------------------------------------------
프로젝트 폴더에 CLAUDE.md 파일을 두면 Claude가 매번 읽고
참고합니다. 프로젝트 규칙이나 자주 하는 설명을 적어두세요.

  예)
  - 이 프로젝트는 순수 HTML/CSS/JS로 만든 웹사이트입니다.
  - 들여쓰기는 스페이스 2칸을 사용합니다.
  - 답변은 한국어로 해주세요.

/init 명령으로 기본 내용을 자동 생성할 수 있습니다.


--------------------------------------------------------------
7. 잘 쓰는 팁
--------------------------------------------------------------
1) 요청은 구체적으로: "예쁘게 해줘"보다
   "헤더 배경을 남색으로, 글자는 흰색으로 바꿔줘"가 좋습니다.
2) 큰 작업은 작게 나눠서 요청하세요.
3) 결과가 이상하면 "왜 그렇게 했어?"라고 물어보세요.
4) 변경 사항은 꼭 직접 확인하고 수락하세요.
5) 작업 전후로 Git 커밋을 해두면 언제든 되돌릴 수 있습니다.
6) 비밀번호, API 키 같은 민감 정보는 입력하지 마세요.
