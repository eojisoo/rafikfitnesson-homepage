- 압축파일의 js/config.js 배포 주소가 채팅에서 사용자가 알려준 주소와 달랐습니다. 사용자 제공 주소로 맞췄습니다. 실제 현재 배포 주소인지 반드시 확인하세요.

적용 방법:
1. 압축파일의 길동/천호 HTML, js 파일을 기존 프로젝트에 덮어씁니다.
2. Google Apps Script 편집기에서 apps-script/Code.gs 내용을 전체 복사해 실제 Code.gs에 붙여넣습니다.
3. Apps Script: 저장 > 배포 > 배포 관리 > 기존 배포 수정 > 새 버전 > 배포.
4. js/config.js의 applicationEndpoint가 실제 기존 배포의 /exec 주소와 동일한지 확인합니다.
5. 브라우저 강력 새로고침 후 한 번만 테스트 신청하고, 시트 저장과 완료 문구를 확인합니다.

주의:
- 테스트 신청은 실제 개인정보 대신 테스트 값으로 하세요.
- 신청 완료 표시는 신청번호+확인토큰으로 실제 시트에 저장된 경우에만 표시합니다.
- 조회가 실패하면 저장된 경우에도 확인 실패 문구가 뜰 수 있으니 재신청 전에 시트를 확인하세요.
- 이 환경에서는 사용자의 실제 구글 계정이나 배포된 웹앱을 직접 실행 테스트하지 못했습니다.
