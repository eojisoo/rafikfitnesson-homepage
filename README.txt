이벤트 배너 (회원권 위) — 구글시트에서 켜고 끄기
----------------------------------------
처음 한 번만 설정:
1. 회원권 상품이 들어 있는 구글시트에 '이벤트' 탭을 추가합니다.
2. 1행에 아래 제목을 그대로 적습니다 (영문 소문자).
   active | branch | label | title | description | period | end | button | category
3. active 열(A열)을 선택하고 삽입 > 체크박스.
4. 파일 > 공유 > 웹에 게시 > '이벤트' 탭 선택 > 형식 'CSV' > 게시 → 나온 주소를
   js/main.js 의 EVENT_CSV_URL='' 따옴표 안에 넣습니다.

각 열 설명:
- active      : 체크하면 표시, 해제하면 숨김
- branch      : gildong(길동점) / cheonho(천호역점) / all(두 지점 모두)
- label       : 배지 문구 (예: OPEN EVENT) — 비우면 EVENT
- title       : 큰 제목 (필수)
- description : 설명 한 줄
- period      : 기간 표시 문구 (예: 2026.11.01 – 11.30)
- end         : 종료일 2026-11-30 — 다음 날부터 자동으로 숨김 (비우면 계속 표시)
- button      : 버튼 문구 — 비우면 '혜택 받고 신청하기'
- category    : 버튼을 누르면 선택될 회원권 탭 gym / yoga / pilates / pt

※ 체크된 줄이 여러 개면 위에 있는 줄 하나만 표시됩니다.
※ 시트를 고친 뒤 홈페이지에 반영되기까지 구글 게시 특성상 최대 5분 정도 걸립니다.

회원권 상품 (02 Membership) — 구글시트 첫 번째 탭에서 관리
----------------------------------------
※ 상품 탭은 반드시 시트 맨 왼쪽(첫 번째 탭)에 두세요.
   등록 신청 시 Apps Script가 첫 번째 탭에서 상품·가격을 다시 확인합니다.
   '이벤트' 탭 등을 상품 탭보다 앞으로 옮기면 신청이 접수되지 않습니다.

1행 제목 (영문 소문자, 그대로 유지):
   id | branch | category | name | price | tag | description | active

각 열 설명:
- id          : 상품 고유 코드 (필수, 영문·숫자·하이픈, 다른 상품과 겹치면 안 됨)
                예) gym-3-g = 헬스 3개월 길동점. 신청 내역에 이 코드가 기록되므로 한번 정하면 바꾸지 마세요.
- branch      : gildong(길동점) / cheonho(천호역점) / all(두 지점 모두)
- category    : 회원권 탭 — gym(헬스) / yoga(요가) / pilates(필라테스) / pt(PT) / barre(바레, 천호역점만)
- name        : 상품 이름 (필수) 예) 헬스 3개월
- price       : 가격 숫자 (필수) 예) 165000 또는 165,000 — '원'은 붙여도 되고 안 붙여도 됨. 0이나 빈칸이면 표시 안 됨
- tag         : 카드 위 작은 영문 문구 예) GYM / 3 MONTHS (비우면 category 값)
- description : 카드 설명 한 줄 예) 24시 헬스 회원권, 필라테스 3개월 24회
- active      : 판매 중이면 TRUE(체크), 내리면 FALSE(체크 해제)

상품 추가: 맨 아래 줄에 새로 입력 → active 체크
상품 내리기: 줄을 지우지 말고 active 체크만 해제 (이전 신청 기록과 맞추기 위해)
가격 변경: price만 수정 (신청 시점의 가격이 신청 시트에 따로 저장됩니다)

※ 홈페이지에는 시트에 적힌 순서대로 표시됩니다.
※ 수정 후 홈페이지 반영까지 최대 5분 정도 걸립니다.
